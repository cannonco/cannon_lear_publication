# Cannon-Lear Publishing WordPress Theme

Custom, builder-free WordPress theme for [books.cannonco.net](https://books.cannonco.net), aligned to the approved `20260829-Cannon_Lear_Publication-Website_Design.pptx` design.

## Included pages

- Publishing homepage
- *Executive Knowledge Management* book page at `/books/ekm/`
- Cory Lee Cannon author page at `/authors/cory-lee-cannon/`
- Contact page at `/contact/`

The theme creates the required page hierarchy when it is activated and flushes WordPress rewrite rules. If replacing an already-active earlier release, briefly activate another theme and reactivate Cannon-Lear Publishing, or resave **Settings → Permalinks**, so the new URLs resolve.

## Installation

Upload `cannon-lear-publishing.zip` through **Appearance → Themes → Add New → Upload Theme**, replace version 1.0.0, and activate version 1.1.0.
